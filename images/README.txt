Put your images in this folder. The site expects two files:

  banner.jpg    The wide photo behind your name on the homepage.
                A landscape image around 1600 to 2000 pixels wide
                works best. Until this file exists, the homepage
                shows a deep navy backdrop instead.

  portrait.jpg  Optional photo of you for the About page. Only
                needed once you swap the grey placeholder for a
                real <img> tag (there is a comment in about.html
                showing the exact line to use).

Project photos can be named anything, e.g. project-1.jpg. The
comments in projects.html show how to swap them in.

If you use different file names, that is fine. Just update the
matching file name in styles.css (for the banner) or in the HTML
(for everything else).

Tip: keep photos under about 500 KB each so the site loads fast.
Free tools like squoosh.app shrink them without visible quality
loss.
